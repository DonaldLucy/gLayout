# Condition: With SMGR + Localizer

This condition contains a private copy of all 24 held-out prompts. An agent assigned here may use SMGR provenance and Localizer output while debugging its own generated layouts.

Use this condition's local folders only:

- `prompts/`: assigned original `.convo` files.
- `workspace/`: scratch files or per-agent setup notes.
- `logs/`: run logs copied from `run_log_template.md`.
- `results/`: completed scorecards or summaries.
- `artifacts/`: generated GDS, reports, provenance sidecars, Localizer output, and patches.

Do not read or copy from `conditions/baseline_no_smgr_localizer/`.
