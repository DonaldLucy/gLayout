# Condition: Baseline Without SMGR + Localizer

This condition contains a private copy of all 24 held-out prompts. An agent assigned here should debug using ordinary repo inspection plus raw Magic DRC and Netgen LVS reports only.

Use this condition's local folders only:

- `prompts/`: assigned original `.convo` files.
- `workspace/`: scratch files or per-agent setup notes.
- `logs/`: run logs copied from `run_log_template.md`.
- `results/`: completed scorecards or summaries.
- `artifacts/`: generated GDS, raw reports, and patches.

Do not read or copy from `conditions/with_smgr_localizer/`.
